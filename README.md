# Lifetime Health Record V13

Updates:
- Separate Patient / Doctor registration.
- Doctor registration: DOB, workplace, required phone, required Gmail/email, searchable multi-degree selector, work type, chamber/work schedule, leaflet photo.
- Doctor directory and messaging.
- Doctor-to-doctor messaging requires friendship.

Important: Netlify Blobs is not a HIPAA-compliant medical-data architecture. Do not use real sensitive medical records in production without appropriate security, encryption, access controls, and professional/legal review.
